# Fire Charge Boost — Fabric 1.16.5

این پروژه یک **مود Fabric** است (نه پلاگین Bukkit/Spigot).

## عملکرد
- Fire Charge را در دست بگیر.
- راست‌کلیک کن تا به سمت بالا پرتاب شوی.
- در Survival یک Fire Charge مصرف می‌شود؛ در Creative مصرف نمی‌شود.
- قدرت پرتاب در فایل `FireChargeBoost.java` با مقدار `1.5D` تنظیم شده است.

## کامپایل
1. JDK 8 یا یک JDK سازگار با Gradle این پروژه نصب کن.
2. پوشه پروژه را در ترمینال باز کن.
3. دستور زیر را اجرا کن:

   `gradle build`

4. فایل خروجی در این مسیر ساخته می‌شود:

   `build/libs/fire-charge-boost-1.0.0.jar`

## نصب
Fabric Loader برای Minecraft 1.16.5 و Fabric API سازگار را نصب کن، سپس فایل JAR را داخل پوشه `mods` قرار بده.

## نکته
پروژه از Fabric Loom قدیمی استفاده می‌کند تا با نسل Minecraft 1.16.5 سازگار باشد. اگر Gradle یا مخزن‌های وابستگی نسخه‌های قدیمی را دریافت نکنند، ممکن است لازم باشد نسخه‌های ابزار ساخت به‌روزرسانی شوند.
